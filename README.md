Electronic Voting Machine (EVM)
An interactive Electronic Voting Machine simulation built using Arduino Uno, a 16x2 LCD Display, and Pushbuttons, designed and simulated on Tinkercad.

Project Overview

This project simulates a digital voting system that allows voters to cast votes for four political parties/options:
BJP
INC
AAP
OTH (Others)
It provides real-time updates on a 16x2 LCD screen, maintains accurate vote counts, signals vote confirmation via LEDs,
and computes the final winning party upon pressing a designated result button.

Components Used
Arduino Uno R3 (1)
16x2 Liquid Crystal Display (LCD) with I2C/Adafruit driver (1)
Pushbuttons (5)
Button 1 (A0): Vote for BJP
Button 2 (A1): Vote for INC
Button 3 (A2): Vote for AAP
Button 4 (A3): Vote for OTH
Button 5 (Pin 7): Display Result / Declare Winner
LEDs:
Green LED (Pin 12): Voting confirmation indicator
Red LED (Pin 13): Result declaration indicator
